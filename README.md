# FRZN™

Landing site for **FRZN** — extreme-cold puffer systems. *Engineered For Cold, Not For Crowd.*

A static site built with plain HTML, CSS, and JavaScript (no build step).

## Structure

```
index.html      # Main page
style.css       # Styles
script.js       # Interactions
assets/img/     # Images
assets/video/   # Video
netlify.toml    # Netlify deploy config
```

## Local preview

Open `index.html` directly, or serve the folder:

```bash
npx serve .
```

## Deploy

Hosted on [Netlify](https://www.netlify.com/). Pushes to `main` deploy automatically.
